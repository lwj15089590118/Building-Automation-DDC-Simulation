# 简历项目描述（150 字以内，可直接粘贴）

**楼宇 DDC 控制与能源管理仿真**（个人项目 · Python 3.12 / numpy / Flask / pymodbus / ECharts）

独立搭建楼宇自控全栈仿真：RC 热网络模拟 3 类房间负荷，DDC 实现 PID 控温（±1℃ 死区）、
水箱位式控制（带回差）、风机联锁顺序、防火阀联锁及 setback 时间表，20 点中文点表经
Modbus/TCP 从站对外暴露，ECharts 大屏实时监控并支持设定值在线修改。仿真验证：
工作时间温度舒适满足率 90.7%~95.7%，节能模式较全天恒温节能 36.8%（130 kWh/天，
均为仿真验证值）。
