# 项目验收清单

> 使用方法：逐项勾选。全部通过即代表项目在本机可完整复现。
> 验收环境要求：Windows 10/11 + Python 3.12，`pip install -r requirements.txt` 已执行。

## 一、环境与依赖

- [ ] `python --version` 显示 3.12.x（3.10+ 兼容）
- [ ] `pip install -r requirements.txt` 安装成功（numpy / flask / pymodbus）
- [ ] 项目目录下 `python -c "import numpy, flask, pymodbus; print('ok')"` 输出 ok

## 二、代码交付完整性

- [ ] `plant/thermal.py`：3 个房间独立 RC 模型、室外温度日曲线、人员/设备/日照时间表、1 分钟步长、测量噪声
- [ ] `plant/water_tank.py`：进水阀→液位上升、出水负载扰动→下降、高低液位限位
- [ ] `ddc/ddc_controller.py`：PID 控温(±1℃死区)、水箱位式控制(回差)、联锁顺序、防火阀联锁、时间表 setback(开关可配)、报警队列
- [ ] `points/point_defs.py` + `point_bus.py` + `modbus_slave.py`：AI1~AI6 / AO1~AO4 / DI1~DI4 / DO1~DO6 中文点表齐全，映射 pymodbus 各寄存器区
- [ ] `points/modbus_client_test.py`：主站自测脚本完整可运行
- [ ] `energy/analyzer.py`：冷量 OP 积分折算 kWh、两策略对比与节能率
- [ ] `dashboard/app.py` + `dashboard/templates/index.html`：ECharts(CDN) 看板全部功能
- [ ] `run_day.py`：快进 1440 分钟×2 策略并自动生成 docs/运行日报.md
- [ ] 全部代码为完整可运行文件，无伪代码、无省略片段，关键逻辑均有中文注释

## 三、功能自检（命令逐条执行）

- [ ] `python -m plant.thermal` —— 打印 48h 温度漂移表且数值合理（夜间降温、午后升温）
- [ ] `python -m plant.water_tank` —— 液位在限位内往复变化
- [ ] `python -m ddc.ddc_controller` —— 打印点表+全天状态摘要+报警队列，退出码 0
- [ ] `python -m energy.analyzer` —— 能耗数量级与期望值一致
- [ ] `python run_day.py` —— 控制台输出节能率，生成 `docs/运行日报.md` 与 2 份 JSON
- [ ] `docs/运行日报.md` 中舒适满足率 ≥90%、节能率为正（仿真验证值）

## 四、看板验收

- [ ] `python dashboard/app.py` 后浏览器打开 http://127.0.0.1:5000 正常渲染
- [ ] 温度趋势曲线滚动更新，SP±1℃ 死区阴影带随设定值切换移动
- [ ] 设备状态灯与 DO/DI 状态一致，水箱液位柱实时变化
- [ ] 报警列表出现注入事件产生的"重要"报警（需运行至对应时刻或等待回放）
- [ ] 能耗柱状图显示"节能开/关/实时"三根堆叠柱（需先跑过 run_day.py）
- [ ] 点击任意房间"+0.5"，SP 数值带"(手动)"标记；点"自动"恢复时间表
- [ ] 回放滑块拖动后曲线截取到历史时刻，"返回实时"恢复
- [ ] 倍速按钮 暂停/60×/300×/600× 生效
